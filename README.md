# Smart Campus Management System – Group C

## Project Overview

This project was developed for CSC1057 – IT Architecture.

The Smart Campus Management System aims to provide a centralised platform for students, staff and administrators to access and manage campus services.

## Project Features

- Secure user authentication
- Role-based access control
- Timetable management
- Room availability
- Attendance management
- Campus announcements
- User management

## Technologies

- React – Frontend development
- Vite – Development and build tool
- AWS Amplify – Cloud hosting and deployment
- AWS Cognito – Identity and access management
- GitHub – Version control and collaboration
- Jira – Project and task management

## System Architecture

The system uses a cloud-based architecture. The frontend is hosted using AWS Amplify and integrates with AWS Cognito to manage user authentication.

## Security

AWS Cognito provides secure authentication through a user pool and an app client.

Three user groups were configured:

- Student
- Staff
- Administrator

The system was designed around role-based access control and the principle of least privilege, where users should only have access to the resources necessary for their role.
